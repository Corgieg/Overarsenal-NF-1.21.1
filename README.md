Welcome
==========
Hello! Welcome to the GitHub :)

This mod aims to implement multiblock digging tools craftable via Overgeared's smithing system.
Current development targets Neoforge and Minecraft version 1.21.1. We don't have plans to port the mod at this time, 
but others are welcome to do so if they wish!

Overgeared is required for this mod to function along its dependencies.
Please, show some love to those mods as well!
